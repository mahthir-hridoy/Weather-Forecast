# 🌦️ Weather Dashboard

A modern, responsive weather application built using **HTML, CSS, JavaScript, Chart.js, and the OpenWeather API**.

</div>

---

## ✨ Features

- 🔍 Search weather by city
- 🌍 City autocomplete suggestions
- 🌡️ Real-time current weather
- 🌡️ Feels Like temperature
- 💧 Humidity
- 💨 Wind Speed
- 👁️ Visibility
- 🌬️ Air Pressure
- ☁️ Weather icons
- 🎨 Dynamic background based on weather
- 📈 Temperature analytics graph
- 🌧️ Rain chance graph
- 🖱️ Interactive floating tooltip
- 📱 Fully responsive design

---

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (ES6)
- OpenWeather API

## 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/yourusername/weather-dashboard.git
```

2. Open the project folder.

3. Open `script.js`.

4. Replace the API key.

```javascript
const apiKey = "YOUR_API_KEY";
```

5. Run `index.html`.
